## Getting Started

### Prerequisites

- Android Studio (latest stable version recommended)
- JDK 11 or higher
- Android SDK (API level 21 or higher recommended)

### Building the Project

1. Clone the repository:
   ```bash
   git clone https://github.com/annnw23/android.git
   cd android
   ```

2. Checkout the `end` branch (if not already on it):
   ```bash
   git checkout end
   ```

3. Build the project using Android Studio or Gradle:
   ```bash
   ./gradlew build
   ```

4. Run the application:
   ```bash
   ./gradlew installDebug
   ```
